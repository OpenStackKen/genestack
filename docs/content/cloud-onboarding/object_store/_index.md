title: "Object Storage"
weight: 50
---

[OpenStack Swift](https://docs.openstack.org/swift/latest/) is a highly available, distributed, eventually consistent object/blob store. Swift allows your to store lots of unstructured data efficiently, safely, and cheaply. 

Swift stores and retrieves data over HTTP. Objects (blobs of data) are stored in an organizational hierarchy.   You can store and retrieve Swift data via an industry-standard HTTP RESTful API.
