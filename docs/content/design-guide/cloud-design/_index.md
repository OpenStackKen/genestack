The cloud architecture includes various components such as virtualization, storage, networking, security, and management tools, all working together to create a flexible and scalable cloud environment. Understanding cloud design concepts is key to determining how you will build your cloud to suit the needs of your organization.

This section provides guidance to help you define the physical and logical structure of a Genestack cloud
before you begin deployment.
