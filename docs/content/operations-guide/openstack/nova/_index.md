This portion of the Operations Guide is focused on Day 2 operations for Nova.  [Nova](https://docs.openstack.org/nova/latest/) is the OpenStack project that provides the capabilities to provide Virtual Machine (VM) instances.

This guide is designed for cloud operators, service administrators, and automation engineers who operate and manage a Genestack cloud in order to support cloud applications and daily operations.
