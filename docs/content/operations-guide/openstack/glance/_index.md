The [Glance](https://docs.openstack.org/glance/latest/) iImage service provides discovery, 
registration, and delivery services for the base operationg system disk and server images. 

In addition to this, Glance provides the ability to copy or snapshot a server image, and immediately 
store it. You can use stored images as templates to create new servers quickly and more consistently 
than repeatedly installing a clean image and individually configuring services the same way each time.
